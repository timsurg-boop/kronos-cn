# 数据格式

## 标准文件

每个标的一个 CSV，文件名 `<code>_kronos.csv`：

```csv
date,open,high,low,close,volume,amount
2024-01-02,1680.0,1695.0,1672.0,1688.0,31200,52600000
2024-01-03,1689.0,1701.0,1683.0,1697.0,28700,48700000
```

| 列 | 类型 | 说明 |
|----|------|------|
| `date` | date | ISO 日期，严格递增，无重复 |
| `open` / `high` / `low` / `close` | float | 前复权价，必须为正 |
| `volume` | float | 成交量（股 / 张 / 币），必须为正 |
| `amount` | float | 成交额（元 / 美元），允许为 0 |

## 代码约定

| 市场 | 写法 | 示例 | 备注 |
|------|------|------|------|
| A 股 | 6 位数字 | `600519`、`000001`、`830799` | 自动判断沪/深/北 |
| 美股 | `<TICKER>USA` | `AAPLUSA`、`SPYUSA` | `USA` 是后缀，不是交易所 |
| 加密 | `<COIN>USA` | `BTCUSA`、`ETHUSA` | 7×24，允许周末行 |

`config.normalize_code()` 会去掉 `.SH` / `.SZ` / `.BJ` 后缀，所以 `600519.SH` 与 `600519` 等价。

## 周期聚合

`data.convert.to_period(frame, freq)`：

| `freq` | 规则 | 用途 |
|--------|------|------|
| `D` | 原样，去重排序 | 预测与评测 |
| `W` | `W-FRI`，周五收盘 | 周线 |
| `M` | `ME`，月末 | 月线 |
| `Q` | `QE`，季末 | 季线 |
| `Y` | `YE`，年末 | 年线 |

聚合规则固定：`open=first`、`high=max`、`low=min`、`close=last`、`volume=sum`、`amount=sum`。

## 质量规则

`kronos-cn validate` 会报告：

1. 缺少 `date` 或 OHLCV 列。
2. 日期无法解析、非递增、重复。
3. 相邻交易日间隔超过 30 天（长假/停牌可解释）。
4. 价格 ≤ 0、`high < low`。
5. 成交量为 0。
6. 非加密标的出现周末行。

退出码：有问题返回 `1`，全通过返回 `0`，方便接 CI。

## 云图对数据的要求

- 至少 25 行，否则跳过。
- 必须有 `date`、`close`、`volume`。
- 周/月聚合后至少各 2 个点，否则不计算周期涨幅。

## 常见坑

**日期丢失**：`to_csv(index=False)` 前忘记把 `trade_date` 改名。用 `convert.normalize()` 统一处理。

**复权口径混用**：同一标的不要一半前复权、一半不复权，否则涨幅与成交量都会跳变。

**盘中快照**：收盘前抓的最后一行成交量偏小，会让云图方块偏小。收盘后重抓即可。

**时区**：CSV 只存日期，不带时区。跨市场比较时以各自交易所的交易日为准。
